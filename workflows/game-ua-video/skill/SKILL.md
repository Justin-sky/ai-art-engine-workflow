# 游戏买量（game-ua-video）

## 这条工作流产出什么

`卖点与旁白（文本）→ 关键分镜图（1 张，竖屏）→ 买量视频（1 条，15 秒，9:16）`

产物是**一条竖屏短视频 + 它的关键帧起步图**。三步各有节点，可以分开重跑：文案不满意只重跑文案，图不满意只重跑图，不必从头来。

## 什么时候用 / 什么时候别用

用：用户明确了是**游戏**，要做**投放 / 买量 / 信息流广告素材**，且希望从一句卖点直接走到一条成片。

别用（用兄弟工作流）：

| 用户其实想要 | 该用 |
|---|---|
| 产品（实物、消费品）广告而不是游戏 | `product-ad`（产品广告） |
| 电商带货、要变体矩阵 / 图层分离 | `ecom-ad-deep`（电商带货） |
| 已经有多张分镜图，只想串成视频 | `storyboard-video`（分镜出片） |
| 剧情向短剧（要节拍、9宫格、多镜头动态） | `short-drama9`（短剧分镜·9格直出）或 `short-drama`（短剧分镜） |

**易错点**：`storyboard-video` 与它的区别是——那条是「先有图（多张、由人给）再出片」；本工作流是「先有卖点文案，图与视频都由工作流生成，且只出**一张**关键帧、**一条**视频」。

## 上游输入怎么给

用户必须提供的是**卖点与旁白文案**，写进「卖点与旁白」节点（`play.script`）的 `text`：

- 建议包含：游戏名 / 品类、目标人群、1~3 个核心卖点或钩子、收尾 CTA。
- 预设里的 `text` 是占位符 `（在此填写游戏卖点、钩子与旁白文案）` —— 不改就跑，等于让模型自由发挥。
- 这个节点的正文会沿 `out`（`text`）流到下游生图节点的 `in-text`，生图节点会把它**接在自己的 `generateInstruction` 之后**一起送进模型。

可选输入：

- 已有游戏截图 / 关键视觉：接到「关键分镜图」的 `in-image`（类型 `image`，multiple）当参考图。
- 风格参考图：走节点参数 `styleImages`（条目须带 `libraryId` 或 `data:` 开头的 `dataUrl`）或工程全局风格，不要指望在文案里写"参考某游戏"就能生效。

## 关键约束与顺序

1. **顺序是硬性的**：`卖点文案 → 关键分镜图 → 买量视频`。视频节点接的是图节点的 `out`；图没出，视频跑起来只会报 `GRAPH_PROCESS_NO_INPUT`。
2. **视频节点默认吃的是"参考图"，不是首帧**。`generateFrameMode` 缺省为 `none`，上游图作为图片参考（`image_url`）提交。要让画面**严格从这张图开始**，得显式把 `generateFrameMode` 设成 `first`（图接到 `in-first-frame`），并用 `in-last-frame` 给尾帧。不要在没有设帧模式的情况下跟用户保证"第一帧就是那张图"。
3. **9:16 与 15 秒是请求值，不是保证值**。执行前会按所选模型的能力表 clamp：模型不支持 15 秒就取最近的合法时长，不支持 9:16 就取能力表里的首选比例。用户抱怨"时长/比例不对"时，先查模型能力，不要反复改同一个参数重试。
4. **一次只出一条视频**。要 A/B 多条素材，做法是改文案 / 分镜提示词后重跑，或复制资产；本工作流没有变体矩阵。
5. **视频节点只有一个上游图连接（工作流预设如此）**，但它的 `in-image` 本身是 `multiple`，可以再接更多参考图（含 `in-video` 参考视频）。参考图总量有上限（默认最多 14 张，且风格图优先占位）。
6. `note.text`（剪辑说明）不参与生成，只给人看。
7. 生成是花额度、不可逆动作；**不要在同一轮里对同一条链反复重跑**。视频是异步长任务，用任务状态轮询，不要靠阻塞等待。

## 常见追问怎么答

- **"能出多条不同卖点的素材吗？"** 不能一次出多条。逐条改文案重跑；要矩阵化变体走 `ecom-ad-deep`（电商带货）那条链路，它的设计就是变体矩阵。
- **"能加字幕 / 配音 / 背景音乐吗？"** 本工作流的节点不产字幕轨、也不配音（视频节点有 `generateAudio` 开关，取决于模型是否支持声音）。文案节点里的"旁白"只是**给模型看的文本**，它不会自己念出来。需要配音走语音节点（`asset.voice` 一族）或 `course-narrate`（知识口播）那条链路，字幕属于成片时间线的事。
- **"能剪成多镜头吗？"** 单条视频内由模型决定镜头；本工作流不做多镜头拼接。要多镜头逐条生成再剪辑，或走 `short-drama9`。
- **"图挺好但视频不像那张图？"** 参考图强度与模型有关；把 `generateFrameMode` 设成 `first` 并接 `in-first-frame` 是最强的"以图起片"手段。
- **"能指定模型吗？"** 可以：节点上的 `generateModel` / `generateProviderInstanceId`，或落盘时用统一模型参数覆盖计划里未指定的节点。
