# 2D 帧动画（anim2d-gif）

## 这条工作流产出什么

`动作序列图（1 张，1 行 4 列）→ 2D帧动画节点 → 4 张逐帧 PNG + 1 个 GIF 动图`

- 逐帧 PNG 从节点的 `out`（当前帧）与 `out-all`（全部帧）两个端口出。
- GIF 从 `out-gif` 端口出，并且**落盘为工程资产**（相对路径写在节点的 `animGifRelativePath`）。
- 「2D帧动画」节点**只切帧、只合成，不生成图**。序列图来自上游 `asset.image` 节点（默认已填「行走」1×4 的提示词）。

## 什么时候用 / 什么时候别用

用：用户要**像素/立绘级的逐帧动画**（行走、奔跑、待机、攻击、受击、放技能），或手里已有一张 sprite sheet 要拆成帧 + GIF。

别用（用兄弟工作流）：

| 用户其实想要 | 该用 |
|---|---|
| 一张图直接变成一段视频 | `storyboard-video`（分镜出片） |
| 剧本/分镜驱动的整条视频 | `game-ua-video`（游戏买量）、`short-drama9`（短剧分镜·9格直出） |
| 角色多视角设定立绘 | `character-sheet`（角色设定） |
| 游戏图标整版切格打包 | `game-icons`（游戏图标包，走 `image.gridSplit` + `image.iconPack`） |

**注意区分**：本工作流出的是**循环动画素材**（GIF/帧序列），不是视频文件；不要把它当"出片"链路用。

## 上游输入怎么给

- **有序列图**：把图片拖到/接到「2D帧动画」节点的 `in` 端口（类型 `image`，`multiple: false`，**只吃一张**）。
- **没有序列图**：直接跑上游「动作序列图」节点（`asset.image`），它按 `generateInstruction` 生成 1 行 4 列、无缝拼接、无格线的 sprite sheet。
- 关键前提是**序列图必须严格等分、格子无缝、无边框/分隔线**。切帧用 `edgeInset: 'auto'` 做过内缩容错，但这不能救一张格线粗、留白大的图 —— 序列图提示词里要明确写上「无边框与分隔线」。
- 要多张参考图当风格/角色参考时，接到「动作序列图」节点的 `in-image`，不要把多张图堆到帧动画节点的 `in`。

## 关键约束与顺序

1. **必须按 `动作序列图 → 2D帧动画` 的顺序跑**。帧动画节点只读上游产出的图；上游没出图就执行，会报 `GRAPH_PROCESS_NO_INPUT`。
2. **帧数是"参数说几格就切几格"，与图里真实的格数必须一致**。`animRows` × `animCols` 是切格依据（两者都 clamp 在 1~6）；写成 1×4 而图上画了 2×4，切出来就是歪的。
3. **GIF 默认关闭**。`animGifFps = 0` 就只切帧、不出 GIF；本工作流预设把它设成了 **12**。上限是 24，超过会被截断到 24；帧数不足 2 帧也不产 GIF。
4. **改 GIF 帧率改的是节点上的 `animGifFps`**，不是 inspector 里播放预览用的 fps（那个只存在浏览器本地，不写进节点）。用户说"太快/太慢"时，先确认他要改的是导出 GIF 还是预览。
5. **不透明背景要去掉时**用 `animKeyColor`：`'black'` 或 `'white'`。它同时作用于生成侧（整张序列图按纯黑/纯白底出图）与切帧侧（键控为透明，GIF 帧也带透明）。角色正常带场景时**不要**设它，否则会把暗部/亮部误键掉。
6. **动作语义是上游序列图的事，不是帧动画节点的事**。`animPresetId` / `animInstruction` 在本工作流里是**生成侧参数**（节点的内图 / 帧序列图生成节点用）；当前 `anim.2d` 执行分支只做切帧与合成，改这两个参数**不会**改变已经生成好的序列图。要换动作，改的是上游「动作序列图」的 `generateInstruction`。
7. `note.text` 节点不参与生成，删了不影响产物。
8. 帧 PNG 与 GIF 的落盘目录可用节点上的 `mediaOutputDir` 指定。

## 常见追问怎么答

- **"能直接出 MP4 / 视频吗？"** 不能。本工作流只出逐帧 PNG 和 GIF。要视频走 `storyboard-video` 或 `game-ua-video`。
- **"能让我改动作、加帧数吗？"** 可以，但两边都要改：把 `animRows`/`animCols` 与序列图提示词里写的分格一起改（例如 1×6 就要两处都写 6），否则切格与画面不匹配。
- **"GIF 没出来？"** 依次确认：`animGifFps > 0`、上游已出图（节点 `animKeyColor`/`animGridImage` 表明跑过）、帧数 ≥ 2、以及执行环境支持帧合成能力（无能力时不产 GIF，但逐帧 PNG 仍然出）。
- **"能骨骼动画 / 让人物真跑起来吗？"** 不能。本工作流是**帧序列**动画，没有绑骨、没有补间、没有运行时播放器。要摆姿势+灯光+镜头的 3D 场景走 `director-previz`（3D导演台预演）。
