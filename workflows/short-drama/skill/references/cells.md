# 宫格索引与格参数速查（short-drama）

这条工作流里有**三套编号**，混用是最常见的错误来源：

| 套 | 用在 | 形态 | 例 |
|---|---|---|---|
| 锚点/宫格号 | 9宫格分镜表、9宫格提取、动态提示词表（9格版） | 整数 1~9 | `3` |
| 组-格 | 4宫格动态分镜表、4宫格提取、动态提示词表 | `"G-C"`，G 1~9、C 1~4 | `"2-3"` |
| 裁切框 | `imageGridSplit.selected` | `"行-列"`（都是 1-based） | `"2-1"` |

**格号 ≠ 裁切框**：9宫格的格 7 在裁切框里是 `"3-1"`；4宫格的格 3 在裁切框里是 `"2-1"`。

## 9宫格（3×3）：格号 → 裁切框

行优先，格 N → `row = ⌊(N-1)/3⌋+1`，`col = (N-1)%3+1`：

| 格 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 裁切框 | 1-1 | 1-2 | 1-3 | 2-1 | 2-2 | 2-3 | 3-1 | 3-2 | 3-3 |
| 参数 `anchorCellIndex` | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |

节点参数（每个提取节点只裁一格）：

```json
{
  "anchorCellIndex": 7,
  "imageGridSplit": { "rows": 3, "cols": 3, "selected": ["3-1"] }
}
```

## 4宫格（2×2）：组-格 → 裁切框

| 格 C | 位置 | 阶段（写在表里） | 裁切框 |
|---|---|---|---|
| 1 | 左上 | 定场 | `1-1` |
| 2 | 右上 | 引入 | `1-2` |
| 3 | 左下 | 冲突 | `2-1` |
| 4 | 右下 | 收尾 | `2-2` |

节点参数（组 2、格 3 为例）：

```json
{
  "gridCellIndex": "2-3",
  "imageGridSplit": { "rows": 2, "cols": 2, "selected": ["2-1"] }
}
```

**组号 G 与锚点号一致**：4宫格拼图组 G 的 `in-image` 参考图就是「宫格提取·格G」。所以组 5 讲的是第 5 个锚点那一小段，不是第 5 场。

## 动态格选择（episode.cellSelect）

- 端口：`in`（text，multiple: false）→ `out`（text）。
- 参数：`cellGroupIndex`（1~9）、`cellIndex`（1~4）；9 格直出版用 `cellGroupIndex: G, cellIndex: 1`。
- 行为：先从上游的**动态提示词表**里按「组-格」取那一条，取到就输出

  ```
  # 格G-C

  <该条正文>
  ```

  取不到再退回按 4宫格动态分镜表取（输出带阶段名），仍取不到就**把上游正文整段透传**。
- 所以提示词表的 `## 镜头N [来源: 4宫格 组x-格y]` 标记丢了，会退化成"整张表当一条提示词"——36 条视频拿到同一段文字。这是最贵的静默失败。

## 动态视频（asset.video）

- 端口：`in-image`（参考图，来自对应 4宫格提取）、`in-text`（动态提示词，来自动态格选择）。
- 定位参数 `motionCellIndex`：`"G-C"`，与 `gridCellIndex` 同构，**但名字不同**。
- `generateDuration`：预设 4（秒），会被模型时长档 clamp。
- 命名：产物名由「宿主资产名 + 节点标题（动态视频·格G-C）+ 时间戳」组成，可直接按节点标题区分是哪一格。

## 常见接错

| 现象 | 原因 |
|---|---|
| 流水线视图里某些格认不出 | 3 个定位参数写混了：9宫格提取要 `anchorCellIndex`、4宫格提取要 `gridCellIndex`、视频要 `motionCellIndex` |
| 某格提取出的是整张拼图 | `imageGridSplit.selected` 写成 `[]`（空数组 = 裁全部）或行列数与拼图不符 |
| 36 条视频画面/动作几乎一样 | 动态提示词表缺少 `[来源: …]` 标记，动态格选择退化为整表透传 |
| 4宫格与对应锚点画风不一致 | 4宫格拼图的 `in-image` 没接「宫格提取·格G」（该边很容易在改图时被删） |
| 9宫格拼图里出现格线/白边影响裁切 | 生成指令里的「无缝拼接、不要边框分隔线白边」被删了；裁切是纯本地等分裁切，不会替你去边 |
| 视频没吃到参考图 | `in-image` 边被删，或把 `generateFrameMode` 设成 `first` 却没接首帧口（该模式下参考图会被弃用） |

## 本地 / 远程边界

- `image.gridSplit`：**纯本地裁切**，不调模型（按整除边界切，相邻格不重叠不留缝）。
- `episode.cellSelect`：**纯文本选取**，不调模型。
- `asset.image` / `asset.video` / `prompt.optimize`：**会调模型**。改这几类节点的参数才需要考虑成本。
