# 产品广告（product-ad）

## 这条工作流产出什么

`卖点文案（文本）→ 产品主视觉图 + 使用场景图（两张图）→ 广告短视频（1 条，10 秒）`

- 一个文案节点扇出到两张图：**产品主视觉**（hero，突出质感）与**使用场景图**（scene，真实使用场景）。
- 视频节点接的是**主视觉图**，产出「产品特写与使用场景结合的短广告」。
- 三条支路可以各自重跑：文案、图、视频互不阻塞（视频要等主视觉出图）。

## 什么时候用 / 什么时候别用

用：用户要**实体产品/消费品**的广告素材（美妆、食品、家居、3C…），需要"卖点 + 主视觉 + 场景 + 短视频"这一套。

别用（用兄弟工作流）：

| 用户其实想要 | 该用 |
|---|---|
| 电商带货、要**变体矩阵**或**图层分离**（一图多版/拆图层） | `ecom-ad-deep`（电商带货） |
| **游戏**买量素材 | `game-ua-video`（游戏买量） |
| 已有分镜图，只想串成视频 | `storyboard-video`（分镜出片） |
| 产品**模特/人像**类处理（磨皮、证件照、人像精修） | 用 `image.portrait` 等专门的人像节点，不要在本工作流里硬做 |

**易错点**：`product-ad` 是**单一主视觉 + 单条视频**的轻量链路；要"一次出很多版/拆图层"就是 `ecom-ad-deep`，不要在本工作流上手动复制粘贴去凑。

## 上游输入怎么给

**必填**：卖点文案，写进「卖点文案」节点（`play.script`）的 `text`：

- 预设占位符是 `（产品名、核心卖点、CTA）` —— 建议按这个结构写全：产品名、核心卖点（1~3 条）、目标人群/场景、收尾 CTA。
- 这个节点是**纯文本节点，不调模型**：你写什么就传什么，它沿 `out`（`text`）流到两张图节点的 `in-text`，生图时会**追加**在各图自己的 `generateInstruction` 之后。

**强烈建议有产品实拍图**：把产品照片接到图节点的 `in-image`（类型 `image`，`multiple`）。这是"我要画的就是这个产品"最可靠的表达方式；只靠文字描述很难保证包装、logo、瓶型一致。主视觉与场景图都可以各接一张。

**风格**：走节点参数 `styleImages` / `styleImagesUseGlobal`（`styleImages` 条目须带 `libraryId` 或 `data:` 开头的 `dataUrl`）或工程全局风格参考图。在产品文案里写"高级感""极简风"效果远不如挂一张参考图。

## 关键约束与顺序

1. **视频依赖主视觉图**：`产品主视觉 → 广告短视频` 是主链。主视觉没出图就跑去跑视频，会报 `GRAPH_PROCESS_NO_INPUT`。
2. **场景图不接视频**（工作流预设里只连了主视觉）。但视频节点的 `in-image` 是 `multiple` —— 想让片子同时参考场景图，手动**加一条连线**即可，不需要另建节点。
3. **视频默认吃的是"参考图"，不是首帧**。`generateFrameMode` 缺省 `none`，主视觉图作为图片参考提交。要让成片严格从主视觉开始，显式设 `generateFrameMode: 'first'` 并把图接到 `in-first-frame`（首尾帧模式与图片参考互斥，启用后会丢掉 `image_url` 类参考）。
4. **10 秒是请求值，不是保证值**：执行前按所选模型的能力表 clamp（不支持的时长取最近的合法值）。同理 `generateAspectRatio` 缺省为空 —— 成片比例由模型能力表定，**用户在意比例就显式写**（如 `9:16` 竖屏、`16:9` 横屏、`1:1` 方图），或落盘工作流时统一指定宽高比。
5. **场景图与主视觉是并行支路**，都从文案节点取文本；改文案不影响已出的图（要重跑图才有变化）。
6. 参考图总量有上限（默认最多 14 张），**风格图优先占位**，端口参考图用剩余额度 —— 图挂太多时靠后的会被截掉。
7. **不要在同一条链上反复重跑**：生图/生视频花额度且不可逆；视频是异步长任务，轮询任务状态，不要阻塞等待。
8. 两张图与视频的落盘目录可用节点上的 `mediaOutputDir` 指定。

## 常见追问怎么答

- **"能出多版/变体吗？"** 本工作流不产变体矩阵。逐版改文案与指令重跑即可；要系统的变体矩阵走 `ecom-ad-deep`（电商带货）。
- **"能加字幕 / 配音 / 背景音乐吗？"** 节点层面不出字幕轨也不配音。`play.script` 里的"文案"只是**给模型看的文本**，不会被念出来，也不会画在图上。需要人声走语音节点（`asset.voice` 一族），字幕/配乐属于成片时间线的事，用相应节点另接。
- **"能保证产品 logo / 包装和实拍一致吗？"** 不能保证。挂实拍图到 `in-image` 能显著提高一致性，但生成模型仍可能改写细节。要严格一致就用实拍图 + 后期合成，而不是靠生成。
- **"视频里为什么没有使用场景？"** 场景图默认没连到视频。把它连到视频节点的 `in-image`（可多接），或在视频的 `generateInstruction` 里明确写"产品特写与真实使用场景结合"。
- **"能指定模型吗？"** 可以：节点上的 `generateModel` / `generateProviderInstanceId`，或落盘时用统一模型参数覆盖计划里未指定的节点。
