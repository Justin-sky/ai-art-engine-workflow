# 漫画出版（comic-publish）

## 这条工作流产出什么

`漫画剧本（文本）→ 分镜图 ×3 → 漫画页`

三类产物，别混淆：

| 产物 | 是什么 |
|---|---|
| 3 张分镜图 | 每张一格画面，普通图片资产；是下一步的素材 |
| 漫画页节点 | 一张「页」的数据（分格 + 台词气泡 + 页面规格），可双击进入编辑器改版式 |
| 导出的 PNG | 页面按 `width × height` 像素合成的成片；**页面背景色留空时是透明底** |

`漫画页` 节点自己也会跑一次生成：它把上游分镜图按分格填进去、用 canvas 合成 PNG 进图库。

## 什么时候用 / 什么时候别用

- 用：一页多格漫画、条漫单页、分镜连页、需要台词气泡与格间距排版。
- 别用：要**连续镜头视频** → `storyboard-video`（分镜出片）或 `short-drama`（短剧分镜）。
- 别用：要**角色多视角设定**（还没到分镜阶段）→ `character-sheet`。
- 别用：把一页拆成素材图层 → `ecom-ad-deep`（电商带货，含图层分离）。

## 上游输入怎么给

1. **剧本**写进文本节点（画布上标题为「漫画剧本」，`play.script`）的 `text` 参数。按格写：每格一段，写清画面描述、台词、情绪与镜头。用 `graph_edit` 的 `node_update` 更新该节点、把正文写进 `params.text` 即可。
2. **画风与角色一致性**写在三张分镜图节点的 `generateInstruction` 里（画布上「分镜图 1/2/3」）。每张图各有一条指令，第 1 格负责定形象，第 2/3 格用「承接第 1 格」的措辞。
3. 剧本的整段文本会随连线注入每张分镜图的提示词（`play.script:out` → 三个图片节点），所以**不要在剧本里写"忽略上面的话"这类会污染画面的东西**。
4. `workflow_use_installed` 的 `generateAspectRatio` 会**覆盖所有图片/视频节点的比例**（三张分镜图一起改）。单格漫画建议竖版（如 `2:3` / `3:4`）；想给某一张单独设比例，就落图后用 `graph_edit` 改那一个节点。

## 关键约束与顺序（为什么）

- **必须先跑分镜图，再跑漫画页**。漫画页 `in-image` 端口接收上游 3 张图；没有上游图又没有任何分格时会报"漫画页为空"（`GRAPH_COMIC_PAGE_EMPTY`）。
- `comic.page` 的 `in-image` 是**多输入口**（类型 `image`，`multiple: true`），三张图分别连一条边，不是串成一条。
- **多出的分镜图去哪了**：跑漫画页时它会按**阅读顺序（先行后列）**把上游图填进**空格**；生成器（cook）只填空格，你在编辑器里手动绑好的格不会被覆盖。如果分镜图比格多，多出来的会被丢掉 —— 先在编辑器里加格或调 `columns`/`rows`。
- 页面里没有分格时，cook 会按阅读顺序自动建格并填图（按 `columns × rows` 上限）。
- 每跑一次分镜图节点，图库会累积（`out` 端口默认取**最新**那张），所以重跑不会"修好"旧图，只会多一张 —— 选中的那张由节点上的 `selectedImageId` 决定。
- 分镜图是「图」，**不含文字**。台词只存在于分格里的台词气泡，必须手动写进分格的 `bubbles`，别指望模型把中文台词画进画面。
- 页面背景色留空 → 导出为透明底 PNG；想要白底或纯色底要在编辑器里设页面背景。

## 常见追问怎么答

- **"要一页更多分镜"**：本工作流固定 3 张分镜图，页面默认网格是 `columns: 3` / `rows: 3`。要更多格就在编辑器里加格或改 `columns`/`rows`（并相应增加图片节点、重连 `comic.page:in-image`）；注意**超过网格容量的图会被丢掉**。
- **"要出多页漫画"**：这是一页的工作流。做多页就复制整套（图 → 页），不是把页数写进同一个节点。
- **"能自动配台词吗"**：不能。气泡文字是页面数据（`text` / `speaker` / `x` / `y` / `tail` / `scale`），本工作流没有任何节点会写它。
- **"成片是视频吗"**：不是，是 PNG 静帧。要动态走 `storyboard-video` 或 `short-drama9`。
- **"台词气泡能拖动缩放吗"**：能，分格与气泡在编辑器里都有手柄。气泡缩放范围 0.5–4 倍。

## 参数去哪查

节点端口、参数与页面数据字段见 `references/ports.md`（含可直接写进 `graph_edit` 的参数名）。

## 操作建议

1. 先确认用户要的是**一张静帧页**，还是要视频 —— 要视频就换工作流，别在这里硬做。
2. 用 `workflow_use_installed` 落下工作流后，先 `graph_edit` 写剧本与画风指令，再让用户确认脚本。
3. 用 `task_run`（整图跑）执行：先出分镜图，再让用户在漫画页编辑器里排版、加气泡，最后导出 PNG。
